# REST API Reference Manual: AI Property Valuation & Lead Scoring Gateway

**Service Version:** `1.0.0`  
**Base URL:** `http://127.0.0.1:8000`  
**Interactive Swagger UI:** `http://127.0.0.1:8000/docs`  
**OpenAPI Specification:** `http://127.0.0.1:8000/openapi.json`  

---

## 1. Authentication & Security
- **API Secret Key:** Authenticate requests by passing the `X-API-Key` header for privileged management routes.
- **CORS Policy:** Enabled for authorized domains and local dashboards.
- **Out-of-Distribution Rejection:** Automatically returns HTTP `422 Unprocessable Content` if inputs violate operational boundaries (e.g. plot size $< 1.0$ or $> 80.0$ Marla).

---

## 2. Core Endpoints Reference

### 2.1 Predict Fair Property Price
`POST /predict/price`

Calculates algorithmic fair market value in PKR, bounds with 10th and 90th percentile prediction intervals, and generates an automated market verdict.

#### Request Body
```json
{
  "city": "Lahore",
  "area_society": "DHA Phase 6",
  "property_type": "House",
  "plot_size_marla": 20.0,
  "bedrooms": 5,
  "bathrooms": 5,
  "age_years": 5.0,
  "is_corner": "Yes",
  "is_park_facing": "No",
  "amenities": "Solar System, Backup Generator, Dedicated Parking",
  "listed_price_pkr": 75000000.0
}
```

#### Response Payload (`200 OK`)
```json
{
  "predicted_price_pkr": 70014200.0,
  "predicted_price_formatted": "7.00 crore",
  "lower_range_pkr": 66513490.0,
  "lower_range_formatted": "6.65 crore",
  "upper_range_pkr": 79432000.0,
  "upper_range_formatted": "7.94 crore",
  "listed_price_pkr": 75000000.0,
  "listed_price_formatted": "7.50 crore",
  "verdict": "Fair Market Price",
  "variance_pct": 7.1,
  "english_summary": "Predicted: 7.00 crore (range 6.65 crore to 7.94 crore). Listed at 7.50 crore -> Fair Market Price (within standard range).",
  "urdulish_summary": "Sahi market qeemat: 7.00 crore (range 6.65 crore se 7.94 crore tak). Demand 7.50 crore bilkul munasib aur market ke mutabiq hai.",
  "disclaimer": "DISCLAIMER: The prices and valuations generated by this platform are automated algorithmic estimates...",
  "model_version": "PropertyValuationModel_v1"
}
```

#### cURL Example
```bash
curl -X POST "http://127.0.0.1:8000/predict/price" \
     -H "Content-Type: application/json" \
     -d '{"city":"Lahore","area_society":"DHA Phase 6","plot_size_marla":20.0,"bedrooms":5,"age_years":5.0}'
```

### 2.2 Score Inbound Lead
`POST /predict/lead-score`

Evaluates incoming lead interaction metrics, estimates deal conversion probability, assigns priority badges (Hot/Warm/Cold), and classifies customer persona.

#### Request Body
```json
{
  "lead_source": "WhatsApp",
  "budget_pkr": 35000000.0,
  "preferred_city": "Islamabad",
  "purpose": "Buy",
  "number_of_calls": 4,
  "avg_call_duration_mins": 3.5,
  "response_time_hours": 0.2,
  "visit_booked": "Yes",
  "days_since_first_contact": 2,
  "objection_raised": "None"
}
```

#### Response Payload (`200 OK`)
```json
{
  "conversion_probability": 0.8914,
  "probability_percentage": "89.1%",
  "priority_tier": "Hot",
  "priority_badge": "🔥 [HOT]",
  "operational_sla": "Call within 1 hour",
  "recommended_action": "Assign Senior Closer. Contact immediately to lock property viewing date.",
  "customer_persona": "Serious First-Time Homebuyer",
  "persona_description": "High engagement, visit booked, seeking residential security and NOC clarity.",
  "explanation_en": "Lead ranked HOT (89.1% probability). Key drivers: On-site Visit Booked (+0.61), Engagement Intensity (+0.34)...",
  "explanation_ur": "Yeh lead HOT hai (89.1%) kyun ke Site visit ka confirm hona, Rabtay ki shiddat ne conversion imkanat barha diye hain.",
  "model_version": "LeadScoringModel_v1"
}
```

### 2.3 Local SHAP Explainability Endpoints
- `POST /explain/price`: Returns positive and negative SHAP price drivers with natural UrduLish explanations.
- `POST /explain/lead`: Returns positive and negative SHAP conversion drivers with actionable advice.

---

### 2.4 Batch Prediction
`POST /predict/batch?dataset_type=auto`

Multipart file upload accepting `.csv` files. Vectorized inference returns processing summary and enriched CSV records.

#### cURL Example
```bash
curl -X POST "http://127.0.0.1:8000/predict/batch" \
     -H "Content-Type: multipart/form-data" \
     -F "file=@leads_batch.csv"
```

---

### 2.5 System Health & Model Metadata
- `GET /health`: Liveness probe reporting engine status.
- `GET /model/info`: Production model versions, algorithms, and test benchmarks.
- `GET /audit/logs?limit=50`: Retrieves recent prediction records from the SQLite audit store.
