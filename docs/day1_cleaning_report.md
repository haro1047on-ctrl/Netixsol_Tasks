## 2. PII Sanitization Invariants & Patterns Enforced

The pipeline enforces strict Pakistani financial privacy patterns:
1. **Pakistani CNIC (13 digits):** Regex `\b\d{5}[- ]?\d{7}[- ]?\d{1}\b` replaced with `42101-XXXXXXX-X`.
2. **Debit/Credit Card PAN (16 digits):** Regex `\b(?:\d{4}[ -]?){3}\d{4}\b` replaced with `4111-22XX-XXXX-9012`.
3. **Pakistani Mobile Numbers:** Regex `\b(?:03\d{2}|(\+92|0092)[ -]?3\d{2})[ -]?\d{7}\b` replaced with `0300-XXXXXXX`.
4. **Pakistani IBAN (24 chars):** Replaced with `PK45ZARY000000XXXXXXXXXX`.
